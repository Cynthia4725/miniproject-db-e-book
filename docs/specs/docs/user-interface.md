# User Interface Documentation

## 1. Persona

### Persona: ผู้ใช้งานร้านหนังสือและอีบุ๊กออนไลน์

**ชื่อสมมติ:** น้องมิน
**อายุ:** 21 ปี
**อาชีพ:** นักศึกษา

**ลักษณะการใช้งาน:**
ใช้งานเว็บไซต์ร้านหนังสือและอีบุ๊กออนไลน์ผ่านคอมพิวเตอร์หรือโทรศัพท์มือถือ เพื่อค้นหา ดูรายละเอียด และเลือกซื้อหนังสือหรืออีบุ๊ก

### Goals

* ค้นหาหนังสือหรืออีบุ๊กที่ต้องการได้ง่าย
* ดูรายละเอียดของหนังสือก่อนตัดสินใจซื้อ
* เพิ่มหนังสือที่ต้องการลงตะกร้า
* ตรวจสอบรายการสินค้าในตะกร้า
* ใช้งานระบบได้โดยไม่ต้องเรียนรู้ขั้นตอนที่ซับซ้อน

### Pain Points

* หากข้อมูลหนังสือไม่เป็นระเบียบ ผู้ใช้อาจค้นหาสินค้าได้ยาก
* หากตะกร้าสินค้าไม่แสดงสถานะที่ชัดเจน ผู้ใช้อาจไม่ทราบว่ามีสินค้าอยู่ในตะกร้าหรือไม่
* หากข้อความ ปุ่ม หรือโครงสร้างหน้าเว็บไม่ชัดเจน อาจทำให้ผู้ใช้สับสนในการใช้งาน

### User Needs

* หน้าระบบที่มีโครงสร้างชัดเจน
* ข้อมูลหนังสือที่อ่านและเปรียบเทียบได้ง่าย
* การนำทางระหว่างหน้าที่เข้าใจง่าย
* การแสดงสถานะของตะกร้าและการทำรายการอย่างชัดเจน

## 2. Wireframe

Wireframe ใช้สำหรับแสดงโครงสร้างและลำดับข้อมูลของหน้าระบบก่อนการออกแบบรายละเอียดด้านสี รูปภาพ และรูปแบบ Visual Design

### 2.1 หน้าแรก / รายการหนังสือ

```text
+------------------------------------------------------+
| E-Book Store                     [Cart] [Login]      |
+------------------------------------------------------+
| Search: [ ค้นหาหนังสือ........................ ]    |
+------------------------------------------------------+
|                                                      |
|                  หนังสือ / E-Book                    |
|                                                      |
| +------------+  +------------+  +------------+       |
| |   Cover    |  |   Cover    |  |   Cover    |       |
| |            |  |            |  |            |       |
| +------------+  +------------+  +------------+       |
| | Book 1     |  | Book 2     |  | Book 3     |       |
| | Price      |  | Price      |  | Price      |       |
| | [View]     |  | [View]     |  | [View]     |       |
| +------------+  +------------+  +------------+       |
|                                                      |
+------------------------------------------------------+
```

### 2.2 หน้ารายละเอียดหนังสือ

```text
+------------------------------------------------------+
| E-Book Store                     [Cart] [Login]      |
+------------------------------------------------------+
|                                                      |
| +----------------+   Book Title                     |
| |                |   ------------------------------ |
| |     Cover      |   Description                    |
| |                |                                  |
| +----------------+   Price                          |
|                       [Add to Cart]                  |
|                                                      |
+------------------------------------------------------+
```

### 2.3 หน้าตะกร้าสินค้า

```text
+------------------------------------------------------+
| E-Book Store                     [Cart] [Login]      |
+------------------------------------------------------+
|                                                      |
|                    Shopping Cart                     |
|                                                      |
| +------------------------------------------------+  |
| | Book / E-Book | Quantity | Price | Action       |  |
| +------------------------------------------------+  |
| | Book 1        |    1     |  xxx  | [Remove]     |  |
| | Book 2        |    1     |  xxx  | [Remove]     |  |
| +------------------------------------------------+  |
|                                                      |
| Total: xxx                                           |
|                                                      |
|                     [Checkout]                       |
+------------------------------------------------------+
```

## 3. Accessibility

การออกแบบส่วนติดต่อผู้ใช้ควรคำนึงถึง Web Accessibility ตามแนวทาง WCAG เพื่อให้ผู้ใช้สามารถเข้าถึงและใช้งานระบบได้อย่างเหมาะสม

### Accessibility Checklist

| รายการตรวจสอบ     | แนวทาง                                                |
| ----------------- | ----------------------------------------------------- |
| โครงสร้างหน้าเว็บ | ใช้ heading และโครงสร้าง HTML ที่มีความหมาย           |
| ปุ่มและลิงก์      | ใช้ข้อความที่สื่อความหมายและเข้าใจได้                 |
| รูปภาพ            | กำหนด alternative text (`alt`) ให้รูปภาพที่มีความหมาย |
| Keyboard          | สามารถใช้งานฟังก์ชันหลักผ่านแป้นพิมพ์ได้              |
| Focus             | แสดงตำแหน่ง Focus ให้ผู้ใช้ทราบอย่างชัดเจน            |
| สี                | ไม่ใช้สีเพียงอย่างเดียวในการสื่อความหมาย              |
| Contrast          | ตรวจสอบความแตกต่างระหว่างสีข้อความและพื้นหลัง         |
| Form              | มี label หรือข้อความกำกับช่องกรอกข้อมูล               |
| Error message     | แสดงข้อความแจ้งข้อผิดพลาดที่เข้าใจง่าย                |
| Responsive        | รองรับการใช้งานบนขนาดหน้าจอที่แตกต่างกัน              |

### การตรวจสอบ Accessibility

สามารถใช้เครื่องมือสำหรับตรวจสอบ Accessibility เช่น Lighthouse หรือ Accessibility Audit ใน Browser Developer Tools

การตรวจสอบควรครอบคลุมหน้าหลัก หน้ารายละเอียดหนังสือ หน้าตะกร้า และหน้าที่เกี่ยวข้องกับการเข้าสู่ระบบหรือการทำรายการ

> **หมายเหตุ:** คะแนนหรือผลการตรวจ Accessibility จริงต้องบันทึกจากการรันเครื่องมือตรวจสอบกับหน้าเว็บของโครงการ ณ เวอร์ชันที่ส่งงาน ไม่ควรระบุคะแนนโดยไม่ได้ตรวจสอบจริง
